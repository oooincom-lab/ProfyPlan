## 0.5.0 — 22.10.2026

**Добавлено**

- `settings.ps1`: окно настроек с полями «Папка обмена», «Интервал», кнопкой выбора папки и сохранением.
- Tray «Настройки» открывает окно, а не Notepad/JSON.
- После сохранения tray перечитывает конфиг и применяет новый интервал/папку.
- `settings.ps1` включён в EXE через PyInstaller `--add-data`.

**Проверено**

- Окно открывается (`MainWindowTitle`), синтаксис PowerShell — 0 ошибок.
- Сборка EXE/Setup 0.5.0 успешна; `status` показывает 0.5.0.

**Ограничения**

- Окно не меняет пароль/токен — только папку и интервал.
- EXE не подписан; MSI/подпись — следующий этап.

## 0.4.0 — 22.10.2026

**Добавлено**

- `installer.py`: self-install EXE, копирование в `%LOCALAPPDATA%\Programs\ProfyPlanCompanion`.
- Ярлык в меню «Пуск», запись в «Установленные программы» (HKCU), автозапуск через Run.
- Setup без GUI: читает `companion-setup.json` рядом с EXE или код из буфера (`id|code|api`).
- `install`, `uninstall`, `setup` команды; `--uninstall` для записи удаления.
- Защита от второго tray-экземпляра (mutex).
- `build.ps1` собирает `ProfyPlanCompanion.exe` и `ProfyPlanCompanionSetup.exe`.

**Проверено**

- Setup EXE установил приложение, создал ярлык/Run/Uninstall-запись.
- Tray-процесс запускается и остаётся; второй экземпляр завершается.
- `--uninstall` удаляет ярлык и запись; каталог очищается с задержкой.
- Публичная ссылка `/companion/ProfyPlanCompanionSetup.exe` отдаёт установщик.

**Ограничения**

- EXE не подписан.
- Установка per-user; MSI/Group Policy — следующий этап.
- Установка per-user; MSI/Group Policy и подпись EXE — следующие.

## 0.3.0 — 22.10.2026

**Добавлено**

- `pair` команда: одноразовый код из ProfyPlan → агентский токен, без email/пароля.
- Серверная привязка: `agent-code` + `/integration/agent/pair`; токен ограничен одним подключением.
- Агентский токен хранится в DPAPI; `sync_once` использует его без логина.
- Кнопка «Создать код привязки» в окне подключения ProfyPlan.
- Проверка: код одноразовый, повторный — 400; агентский токен видит интеграцию, но получает 403 на `/projects`.

**Ограничения**

- Мастер установки и подпись EXE — следующие.
- Один активный агентский токен на подключение (повторная привязка отзывает предыдущий).

## 0.2.0 — 22.10.2026

**Добавлено**

- `tray` команда и `tray.py`: иконка, статус, «Синхронизировать сейчас», открыть папку, настройки, выход.
- Фоновый цикл обмена в tray; статус обновляется по результату.
- `install.ps1 -Tray` — задача только на вход, запуск версии с иконкой.
- `requirements.txt` (`pystray`, `Pillow`); сборка EXE с hidden imports.
- EXE с tray ~15,8 МБ.

**Проверено**

- `ProfyPlanCompanion.exe --help` содержит `tray`.
- `status` показывает 0.2.0.
- Tray-процесс запускается и остаётся активным (проверено, затем остановлен).
- Сборка PyInstaller с pystray успешна.

**Ограничения**

- Tray не имеет окна настроек — открывает конфиг в Notepad.
- Нет pairing-кода и подписи EXE.

## 0.1.1 — 22.10.2026

## Правило версионирования

1. Любое изменение кода companion повышает версию в `agent.py`.
2. Запись добавляется в этот файл: версия, дата, добавлено/исправлено/проверено/ограничения.
3. При изменении архитектуры обновляется `ABOUT.md`; при изменении запуска — `README.md`.
4. Изменение companion дополнительно фиксируется в общем промте, плане и тест-плане.
5. Версия и changelog входят в тот же коммит, что и код, или в связанный docs-коммит.
