## 0.7.1 — 22.10.2026

**Изменено**

- Companion больше не описывается как «обмен с 1С:УНФ»: это универсальный модуль файлового обмена ProfyPlan с учётными системами.
- Заголовок окна проверки: «Модуль обмена данными»; настройки: «Настройки модуля обмена».
- В «О программе»: «Универсальный модуль обмена файлами ProfyPlan с учётными системами. 1С:УНФ — один из коннекторов».
- README и описание модуля обновлены: 1С:УНФ — первый коннектор, не единственная целевая система.

**Проверено**

- PowerShell-скрипты разбираются без ошибок.
- Версия 0.7.1 собрана; Setup/version.json обновлены; хеш совпадает.

**Ограничения**

- EXE не подписан.

## 0.8.0 — 22.10.2026

**Добавлено**

- `service.py` + `vendor/winsw.exe`: Windows-служба `ProfyPlanCompanion`, автоматический старт до входа пользователя.
- Машинный DPAPI (`dpapi-machine:`) и конфиг в `C:\ProgramData\ProfyPlanCompanion`; ACL SYSTEM/Administrators.
- Команды `install-service`, `uninstall-service`, `service-status`; `install --service` и `Setup.exe --service`.
- `installer.py`: обновление останавливает/переустанавливает службу; после обновления запускает её снова.
- `SERVICE.md`; WinSW включён в PyInstaller-сборку.

**Проверено**

- Служба установлена локально: `Automatic`, `Running`, `LocalSystem`.
- Токен расшифровывается машинным DPAPI; служба дошла до API (в тесте — 401 из-за старого токена).
- `install --service` устанавливает приложение и службу; `service-status` работает.

**Ограничения**

- Установка/обновление службы требуют администратора.
- Сетевые папки с отдельными учётными данными и истечение agent token — отдельные сценарии.
- Clean-machine тест, подпись EXE/MSI и UI управления службой ещё не выполнены.

## Правило версионирования

1. Любое изменение кода companion повышает версию в `agent.py`.
2. Запись добавляется в этот файл: версия, дата, добавлено/исправлено/проверено/ограничения.
3. При изменении архитектуры обновляется `ABOUT.md`; при изменении запуска — `README.md`.
4. Изменение companion дополнительно фиксируется в общем промте, плане и тест-плане.
5. Версия и changelog входят в тот же коммит, что и код, или в связанный docs-коммит.
