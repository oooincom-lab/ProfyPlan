# ProfyPlan — обмен файлами (Chromium)

Расширение для Chrome, Microsoft Edge, Opera и Яндекс Браузера. Читает входящие пакеты `profyplan.exchange.v1` из выбранной папки, отправляет их в портал, забирает исходящие пакеты и складывает в `out`.

## Что умеет

- Выбор папки обмена на этом компьютере (File System Access API).
- Отправка `*.json` из `in` в `/v1/integration/connections/{id}/import-file`.
- Перенос обработанных файлов в `processed`.
- Получение списка `outbox`, скачивание файлов и подтверждение через `ack`.
- Один активный обмен на подключение: lease с heartbeat, конфликт 409.
- Статус, последняя синхронизация и кнопка «Синхронизировать сейчас».

## Установка (распакованная сборка)

1. Откройте `chrome://extensions` (или `edge://extensions`, `opera://extensions`, `browser://extensions` в Яндексе).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `extensions/exchange-chromium`.
4. Откройте портал ProfyPlan и войдите — расширение подхватит токен из localStorage.
5. Откройте настройки расширения (иконка → «Настройки»):
   - обновите список подключений;
   - выберите «УНФ ТОПЕКС (тест)» или другое подключение;
   - выберите папку обмена;
   - включите обмен и нажмите «Сохранить».
6. Нажмите «Синхронизировать сейчас» для проверки.

## Структура папки

Выбранная папка — корень обмена:

```
<выбранная папка>/
  in/            # 1С кладёт входящие пакеты
  out/           # ProfyPlan кладёт исходящие пакеты
  processed/     # обработанные входящие
```

Расширение создаёт подпапки автоматически.

## Как защищён обмен

- Один lease на подключение. Вторая вкладка или второй компьютер получает `409 lease_busy` и видит держателя.
- Heartbeat продлевает lease; без него lease истекает и обмен останавливается.
- Повторная обработка отсекается ключом `имя|размер|mtime` и серверным `packet_id`.
- Расширение не слушает входящие порты; только исходящие HTTPS-запросы к порталу.
- Токен портала берётся из `localStorage` страницы; пароль в расширение не передаётся.

## Ограничения

- Только Chromium-браузеры. Firefox и Safari не поддерживают File System Access API — для них нужен companion с native messaging.
- Обмен работает, пока браузер запущен. Для расписания 07:00 без браузера нужен агент-служба.
- Разрешение на папку может потребовать повторного подтверждения после перезапуска браузера.
- Расширение не опубликовано в магазинах; для пилота используется распакованная сборка.

## Используемые API

- `GET /v1/integration/connections`
- `POST /v1/integration/connections/{id}/import-file`
- `GET /v1/integration/connections/{id}/outbox`
- `GET /v1/integration/connections/{id}/files/{name}`
- `POST /v1/integration/connections/{id}/outbox/{name}/ack`
- `POST /v1/integration/connections/{id}/lease`
- `POST /v1/integration/connections/{id}/lease/heartbeat`
- `DELETE /v1/integration/connections/{id}/lease`
- `GET /v1/integration/connections/{id}/lease`

## Сборка для магазинов

- Chrome Web Store: zip содержимого папки `exchange-chromium`.
- Edge Add-ons: тот же zip, отдельная публикация.
- Opera Add-ons: тот же zip.
- Яндекс Браузер: Chrome Web Store или каталог расширений Яндекса.
- Firefox/Safari: отдельные сборки, см. архитектурную заметку.

## Проверка

1. В портале создайте подключение и откройте его окно.
2. В расширении выберите подключение и папку.
3. Положите тестовый `ping.json` в `in` — он должен уйти в журнал, файл переместиться в `processed`.
4. Сформируйте исходящий пакет в портале — файл должен появиться в `out`.
5. Откройте вторую вкладку/второй браузер: второй обмен должен получить `409` и показать держателя.
