Имена и совместное планирование

Зафиксированы правила переименований и границы двустороннего режима: 1С отвечает за учётные документы, ProfyPlan — за планировочные поля.

1. Имена

name

Рабочее имя в ProfyPlan. Редактируется пользователем.

external_name

Текущее имя в 1С. Только для чтения, обновляется импортом.

external_name_ack

Имя из 1С, которое пользователь уже принял или отклонил.

name_overridden

Пользователь закрепил локальное имя.

2. Режим «Совместное планирование»

1С — ведущая система

Справочники, заказы и факты идут из 1С. ProfyPlan возвращает только зафиксированный план.

Совместное планирование

1С остаётся владельцем учётных документов, а ProfyPlan может менять разрешённые планировочные поля.

Главное правило: 1С отвечает за то, что это за документ и что фактически произошло. ProfyPlan отвечает за то, как это спланировать. Бухгалтерские документы из ProfyPlan не создаются.

4. Конфликты и что не мигрирует

Конфликт

Если обе стороны изменили одно поле — запись в «Конфликты обмена» с выбором стороны. Молча не перезаписываем.

Проведённые документы

1С не принимает изменения из ProfyPlan автоматически. Сначала документ должен быть доступен для изменения.

Не мигрирует

Проводки, налоги, оплаты, остатки, номера, даты, проведение и полные копии документов.

Идемпотентность

Пакеты и операции обмена имеют UID; повторный пакет не создаёт дубль.

5. Настройки

В подключении — один переключатель режима. В свёрнутом блоке «Дополнительно»: создание черновиков заказов в 1С, приём/передача имён, список типов сущностей и политика конфликтов.
