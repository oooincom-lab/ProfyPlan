# ProfyPlan — Шаблон импорта данных · Описание

> Версия 1.0 · 06.08.2026 · Файл: `import-template-7tab.xlsx`

---

## Назначение

Единый Excel-шаблон для импорта данных в ProfyPlan. Подходит для любого режима: простое производство, сложное производство с BOM, строительство с этапами.

**Принцип:** заполняете что нужно — пустое игнорируется. Один файл на все сценарии.

---

## Структура (7 вкладок)

| # | Вкладка | Назначение | Когда обязательна |
|---|---|---|---|
| 1 | Настройки | Глобальные параметры проекта | Всегда |
| 2 | Заказы | Список производственных заказов | Всегда |
| 3 | BOM | Состав изделия (дерево) | Для сборки / производства |
| 4 | Ресурсы | Справочник ресурсов | Опционально (автосоздание) |
| 5 | Маршруты | Операции и их последовательность | Всегда |
| 6 | Этапы | Этапы строительства / производства | Если uses_phases=true |
| 7 | Подразделения | Цеха, участки, площадки | Опционально |

---

## Обозначения в шаблоне

| Знак | Значение |
|---|---|
| `*` | Обязательно всегда |
| `†` | Обязательно только если `uses_phases = true` |
| без знака | Опционально |

## Вкладка 1: Настройки

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| Название проекта | текст | ✅ | Имя проекта в системе |
| Режим | `производство` или `строительство` | ✅ | Влияет на доступные функции |
| Использовать этапы | `да` или `нет` | ✅ | Включает этапное планирование |
| Методы расчёта | текст через запятую | ❌ | `cpm`, `pert`, `ccpm`. Пусто = пользователь выберет |
| Страна | ISO-код | ❌ | `RU`, `KZ`, `BY` — для календаря |

### Логика «Методы расчёта»
- **Не заполнено** → в интерфейсе проекта показывается выбор метода. Пользователь сам решает.
- **Заполнено** (`cpm,pert`) → система проставляет как предустановку. Пользователь может изменить.

## Вкладка 3: BOM (состав изделия)

Плоская таблица parent-child. Глубина вложенности не ограничена.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| Спецификация | текст | ✅ | Код спецификации |
| Узел ID | текст | ✅ | ID узла (1, 1.1, 1.1.1) |
| Родитель | текст | ❌ | ID родительского узла |
| Тип | `сборка`/`полуфабрикат`/`материал`/`фантом` | ✅ | |
| Номенклатура | текст | ✅ | Название |
| Ед. | текст | ❌ | `шт`, `кг`, `м`, `л` |

## Вкладка 4: Ресурсы

Справочник. Можно не заполнять — тогда ресурсы создадутся автоматически из названий в колонке «Ресурс» в Маршрутах.

| Поле | Тип | Описание |
|---|---|---|
| ID ресурса | текст | Код (R-01) |
| Название | текст | |
| Тип | `оборудование`/`персонал`/`бригада`/`инструмент`/`транспорт` | |
| Подразделение | текст | Ссылка на вкладку 7 |
| Доступно | число | Количество |
| Ед. | текст | `шт`, `чел` |

## Вкладка 5: Маршруты

Каждая строка = одна операция.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| Узел ID | текст | ❌ | Ссылка на BOM-узел |
| № оп. | число | ✅ | Порядковый номер |
| Операция | текст | ✅ | Название |
| Ресурс | текст | ❌ | Из вкладки 4 (или автосоздание) |
| Этап | число | † | Номер этапа из вкладки 6 |
| Подразделение | текст | ❌ | Из вкладки 7 |
| Длит.,ч | число | ✅ | Длительность в часах |
| Предш. оп. | число | ✅ | № предыдущей операции |
| Доп. материал | текст | ❌ | |
| Расход | число | ❌ | |
| Вых. год. | число | ❌ | 0.0 — 1.0, по умолчанию 1.0 |

**Авто-последовательность:** если «Предш. оп.» пусто и операция не первая, система выстраивает цепочку по порядку № оп.: 1 → 2 → 3.

Всегда опционально. Если заполнено — CPM учитывает территориальную привязку ресурсов и транспортное время между подразделениями.

| Поле | Тип | Описание |
|---|---|---|

| Мощность в сутки | текст | `120 чел-ч`, `200 м²/сут` |

## Три уровня сложности

### 🟢 Минимальный — «просто список задач»

Заполняются только обязательные поля: Настройки, Заказы (ID, продукт, кол-во), Маршруты (операция, длительность, предш. оп.).

BOM, Ресурсы, Этапы, Подразделения — не заполняются.

### 🟡 Производство — «с BOM и ресурсами»

Заполняются: Настройки, Заказы, BOM, Ресурсы, Маршруты.

Этапы — только если используется поэтапная сборка.

### 🔴 Строительство — «с этапами и подразделениями»

Заполняются: Настройки (режим `строительство`, `uses_phases=да`), Заказы, Ресурсы, Маршруты (с этапами), Этапы, Подразделения.

BOM — редко нужен.

## Правила валидации при импорте

| Проверка | Уровень |
|---|---|
| `uses_phases=да`, а вкладка «Этапы» пуста | ❌ Ошибка |
| `uses_phases=да`, а операция без номера этапа | ❌ Ошибка |
| Оборванная ссылка BOM (родитель не существует) | ⚠️ Предупреждение |
| Цикл в BOM | ❌ Ошибка |
| Узел типа `assembly`/`semi_finished` без маршрута | ⚠️ Предупреждение |
| Ресурс в Маршрутах не найден в справочнике | ℹ️ Автосоздание |
| Подразделение в Маршрутах не найдено в справочнике | ⚠️ Предупреждение |

---

## Автоматические действия при импорте

1. **Автосоздание ресурсов** — если ресурс указан в Маршрутах, но отсутствует во вкладке «Ресурсы», система создаёт ресурс автоматически
2. **Авто-последовательность операций** — если «Предш. оп.» не заполнена, строится цепочка по порядку № оп.
3. **Сохранение справочников** — BOM, ресурсы и подразделения сохраняются для переиспользования в будущих проектах
4. **ext_id** — внешние ID из ERP сохраняются для обратной интеграции
