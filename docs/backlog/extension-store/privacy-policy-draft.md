# Политика конфиденциальности расширения ProfyPlan — обмен файлами

**Черновик.** Перед публикацией разместить на `https://profyplan.ru/privacy/extension` и указать ссылку в карточке Chrome Web Store.

## 1. Что делает расширение

Расширение помогает обмениваться файлами между выбранной папкой на компьютере пользователя и его учётной записью ProfyPlan. Оно не собирает аналитику и не передаёт данные третьим лицам.

## 2. Какие данные обрабатываются

| Данные | Зачем | Где хранятся |
|---|---|---|
| Токен авторизации ProfyPlan | Запросы к API от имени пользователя | Локально в браузере (storage расширения) |
| Имя и идентификатор подключения | Выбор подключения к 1С | Локально в браузере |
| Содержимое файлов `*.json` из выбранной папки | Обмен пакетами с ProfyPlan | Передаётся в ProfyPlan; копия остаётся в папке и `processed` |
| Метаданные файлов (имя, размер, время) | Контроль повторной обработки и журнал | Локально и в журнале ProfyPlan |
| Статус обмена и ошибки | Отображение состояния | Локально в браузере и журнале ProfyPlan |

Расширение **не** читает файлы за пределами папки, которую пользователь выбрал вручную, и **не** собирает историю браузера, пароли или данные других сайтов.

## 3. Правовые основания и цели

Данные обрабатываются для исполнения договора с пользователем (обмен данными с его учётной записью ProfyPlan) и по его явному действию (выбор папки и включение обмена).

## 4. Передача данных

Данные передаются только на сервер ProfyPlan, указанный в настройках подключения, по HTTPS. Расширение не передаёт данные в рекламные сети, аналитические сервисы или иные сторонние системы.

## 5. Хранение и удаление

- Токен и настройки хранятся локально до удаления расширения или очистки данных.
- Файлы в папке обмена хранятся по правилам пользователя; расширение не удаляет исходные данные без перемещения в `processed`.
- Журнал ProfyPlan хранится по правилам продукта (по умолчанию 30 дней для обмена).

## 6. Управление доступом

Пользователь может:

- не выбирать папку и не включать обмен;
- отключить обмен в настройках;
- удалить расширение и очистить его данные;
- отозвать доступ к ProfyPlan через выход из учётной записи.

## 7. Безопасность

- соединение только по HTTPS;
- расширение не слушает входящие порты;
- доступ к папке ограничен выбранным каталогом;
- токен не записывается в журналы и не передаётся третьим лицам.
