# Чек-лист публикации Chromium-расширения

**Статус:** BACKLOG · выполнять на финальной стадии проекта или по запросу клиента.
**Связанные файлы:** `extensions/exchange-chromium`, `apps/web/public/extension/index.html`, `store-listing-ru.md`, `privacy-policy-draft.md`, `production-manifest.json`.

## 1. Подготовка production-сборки

- [ ] Скопировать `extensions/exchange-chromium` в отдельную папку `dist/store`.
- [ ] Заменить `manifest.json` на `production-manifest.json` (только `https://profyplan.ru/*`, без localhost).
- [ ] Добавить иконки:
  - `icons/icon16.png`
  - `icons/icon32.png`
  - `icons/icon48.png`
  - `icons/icon128.png`
- [ ] Проверить, что в ZIP нет `README.md`, тестовых файлов и локальных путей.
- [ ] Проверить `node --check` всех JS и валидность manifest.
- [ ] Установить ZIP в чистый профиль Chrome/Edge и пройти smoke: настройки, токен, выбор папки, ping.

## 2. Магазин Chrome Web Store

- [ ] Аккаунт разработчика Chrome Web Store (разовая оплата $5).
- [ ] Подтвердить email и платёжный профиль.
- [ ] Создать item: язык «Русский», категория «Продуктивность».
- [ ] Загрузить ZIP.
- [ ] Заполнить название, краткое и полное описание из `store-listing-ru.md`.
- [ ] Загрузить скриншоты 1280×800 или 640×400 (минимум 1, лучше 3):
  - окно настроек;
  - popup со статусом;
  - блок «Обмен на этом компьютере» в ProfyPlan.
- [ ] Загрузить иконку магазина 128×128 и small promo tile 440×280.
- [ ] Указать privacy policy URL (разместить `privacy-policy-draft.md` на `profyplan.ru/privacy/extension`).
- [ ] Заполнить обоснование разрешений:
  - `storage` — настройки и токен;
  - `alarms` — периодическая синхронизация;
  - `host_permissions` — API ProfyPlan;
  - доступ к папке — только выбранная пользователем папка через File System Access API.
- [ ] Раскрыть использование данных: JWT, содержимое обменных файлов, метаданные подключения.
- [ ] Выбрать видимость: **Unlisted** для пилота, **Public** после принятия.
- [ ] Отправить на проверку.

## 3. Edge Add-ons

- [ ] Тот же ZIP; отдельная карточка Edge Add-ons.
- [ ] Проверить, что manifest не содержит Chrome-only полей.
- [ ] Указать те же privacy policy и разрешения.
- [ ] Отправить на проверку.

## 4. Opera / Яндекс Браузер

- [ ] Opera Add-ons: тот же ZIP, отдельная карточка.
- [ ] Яндекс Браузер: Chrome Web Store или каталог расширений Яндекса — уточнить актуальный порядок.
- [ ] Проверить установку и работу в каждом браузере.

## 5. После публикации

- [ ] Получить store ID расширения.
- [ ] Добавить `externally_connectable` для `https://profyplan.ru/*`.
- [ ] Обновить страницу `/extension/index.html`: кнопки магазинов вместо ZIP.
- [ ] Добавить в ProfyPlan авто-обнаружение расширения:
  - страница отправляет `PING` по store ID;
  - если ответа нет — показывает «Установить»;
  - если ответ есть — показывает «Подключить этот компьютер».
- [ ] Обновить `help.ts`: установка из магазина, ограничения.
- [ ] Зафиксировать версию и дату публикации в реестре.

## 6. Критерии готовности

- [ ] Чистый профиль Chrome устанавливает расширение из store за ≤ 3 клика.
- [ ] После установки ProfyPlan обнаруживает расширение и предлагает привязку.
- [ ] Обмен `in/out/processed` работает на тестовой папке.
- [ ] Вторая вкладка/машина получает `409 lease_busy`.
- [ ] Privacy policy доступна по HTTPS.
- [ ] Store-карточка не содержит localhost и тестовых данных.

## Оценка

- Подготовка ассетов и текстов — 0,5–1 день.
- Проверка магазина Chrome — обычно 1–5 рабочих дней.
- Edge/Opera/Яндекс — отдельные проверки, 1–3 дня каждый.
- Публикация не блокирует companion и пилот.
