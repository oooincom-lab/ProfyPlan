# Публикация Chromium-расширения — отложенный этап

**Статус:** BACKLOG · не делать до завершения проекта или отдельного запроса клиента.
**Дата фиксации:** 22.10.2026.
**Решение:** сначала companion-приложение; расширение оставить как «lite»-режим и опубликовать в магазинах на финальной стадии.

## Что уже готово

- Chromium-расширение: `extensions/exchange-chromium` (Chrome, Edge, Opera, Яндекс Браузер).
- Серверный lease и outbox: миграция `0030_exchange_leases`, API `/v1/integration/connections/{id}/lease`, `/outbox`.
- Проверено в Edge: manifest, service worker, options, popup, токен портала, список подключений.
- Установочный ZIP: `apps/web/public/extension/profyplan-exchange-chromium.zip`.
- Страница установки: `/extension/index.html`, блок в окне подключения.

## Почему отложено

1. Основной продукт для клиента — companion: работает без браузера, по расписанию, с папками на сервере 1С и UNC.
2. Расширение не видит папку на сервере 1С и не работает при закрытом браузере.
3. Firefox и Safari всё равно требуют companion/native messaging; публикация Chromium-версии не закрывает весь список.
4. Публикация требует store-ассетов, privacy policy и проверки; это не блокирует пилот.

## Триггер возврата

Вернуться к публикации, когда:

- завершается проект (финальная стадия), **или**
- появился клиент, которому нужен именно браузерный вариант без установки companion, **или**
- принято решение сделать публичный каталог расширений.

## Что делать при возврате

Открыть `store-publication-plan.md` и выполнить чек-лист. Не публиковать текущий ZIP «как есть»: в нём остались localhost-разрешения и нет иконок.

## Файлы

- `store-publication-plan.md` — пошаговый чек-лист.
- `store-listing-ru.md` — тексты карточки и обоснование разрешений.
- `privacy-policy-draft.md` — черновик политики конфиденциальности.
- `production-manifest.json` — эталон production-manifest (без localhost).
