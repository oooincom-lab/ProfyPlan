# Карточка расширения (черновик RU)

## Название

ProfyPlan — обмен файлами

## Краткое описание (до 132 символов)

Локальный обмен пакетами ProfyPlan: папка на компьютере, без ручной загрузки файлов.

## Полное описание

ProfyPlan — обмен файлами помогает настроить файловый обмен между 1С и ProfyPlan на компьютере, где лежит папка обмена.

Что делает расширение:

- читает входящие пакеты `*.json` из выбранной папки и отправляет их в ProfyPlan;
- забирает исходящие пакеты плана и складывает их в папку;
- переносит обработанные файлы в `processed`, чтобы они не обрабатывались повторно;
- показывает статус, последнюю синхронизацию и ошибки;
- защищает от одновременного обмена из двух вкладок или с двух машин.

Как это работает:

1. Войдите в ProfyPlan и откройте настройки расширения.
2. Выберите подключение к 1С и папку обмена.
3. Включите обмен — расширение проверяет папку раз в минуту.

Ограничения:

- работает, пока открыт браузер;
- поддерживает Chrome, Edge, Opera и Яндекс Браузер;
- для Firefox и Safari, а также для обмена без открытого браузера нужен companion-агент ProfyPlan.

Конфиденциальность:

- расширение не собирает аналитику и не передаёт данные третьим лицам;
- читает только выбранную пользователем папку;
- токен портала хранится локально в браузере и используется только для запросов к ProfyPlan;
- содержимое файлов передаётся только в ProfyPlan пользователя.

## Обоснование разрешений

| Разрешение | Зачем |
|---|---|
| `storage` | Сохранить настройки, идентификатор подключения, статус и локальный токен |
| `alarms` | Периодическая проверка папки и heartbeat сессии обмена |
| `host_permissions: https://profyplan.ru/*` | Отправка и получение пакетов через API ProfyPlan |
| Доступ к папке (File System Access API) | Чтение и запись только той папки, которую пользователь выбрал вручную |

## Что НЕ делает расширение

- не читает другие файлы и папки;
- не устанавливает и не запускает программы;
- не отправляет данные в сторонние сервисы;
- не содержит удалённого кода и `eval`;
- не работает, если пользователь не выбрал папку и не включил обмен.
