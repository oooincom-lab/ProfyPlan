# Финальный чек-лист проекта

**Статус:** отложено владельцем 22.10.2026. Не входит в текущий срез, но обязательно к завершению проекта.

## Коммерческий Code Signing

- [ ] Купить и зарегистрировать **коммерческий Code Signing сертификат** (OV или EV) у доверенного CA/реселлера.
- [ ] Импортировать сертификат с приватным ключом в хранилище Windows или подготовить PFX/токен для CI.
- [ ] Установить Windows SDK Signing Tools (`signtool.exe`).
- [ ] Подписать `ProfyPlanCompanion.exe`, `ProfyPlanCompanionSetup.exe` и `ProfyPlanCompanion-*.msi`.
- [ ] Проверить `signtool verify /pa` на каждом файле.
- [ ] Проверить установку MSI на чистой машине без самоподписанного корня.
- [ ] Проверить SmartScreen/UAC и отображаемое имя издателя.
- [ ] Зафиксировать thumbprint/срок действия и владельца сертификата в защищённом месте.

**Почему:** самоподписанный сертификат годится только для контролируемого пилота; для публичных клиентов нужен сертификат, которому Windows доверяет без ручной установки корня.
